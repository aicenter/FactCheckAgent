# Fact Check Report

## Statement
Tenhle zákon (nominační, pozn. Demagog.cz) v roce 2020 zavedla vláda Andreje Babiše s tou argumentací (...) „ať je výběr do důležitých funkcí transparentní, ať je odborný“.

## Report
<p class="perex">Nominační zákon byl <a href="https://www.psp.cz/eknih/2017ps/stenprot/026schuz/bqbs/b14703301.htm">vládním návrhem</a> kabinetu Andreje Babiše. Vláda jej ve Sněmovně hájila jako cestu k <a href="https://www.psp.cz/eknih/2017ps/stenprot/026schuz/bqbs/b14703301.htm">transparentnějšímu výběru</a> nominantů a zákon od <a href="https://www.zakonyprolidi.cz/cs/2019-353">4. ledna 2020</a> zavedl i <a href="https://www.zakonyprolidi.cz/cs/2019-353#p11">požadavek odborných předpokladů</a>.</p>
<p>Vít Rakušan mluvil o <a href="https://www.zakonyprolidi.cz/cs/2019-353#p1">zákonu č. 353/2019 Sb.</a>, který se přímo označuje jako nominační zákon. Ten upravuje výběr lidí do <a href="https://www.zakonyprolidi.cz/cs/2019-353#p1">řídících a dozorčích orgánů právnických osob s majetkovou účastí státu</a>, nejde tedy obecně o všechny státní funkce. V tomto bodě je výrok zkratkovitý, jeho jádro ale odpovídá skutečné předloze.</p>
<p>Při prvním čtení ve Sněmovně tehdejší ministr spravedlnosti Jan Kněžínek mluvil o <a href="https://www.psp.cz/eknih/2017ps/stenprot/026schuz/bqbs/b14703301.htm">vládním návrhu nominačního zákona</a>, který má zavést <a href="https://www.psp.cz/eknih/2017ps/stenprot/026schuz/bqbs/b14703301.htm"><i>„jednotná a transparentní pravidla“</i></a> pro výběr členů orgánů státních firem. Ve třetím čtení pak tehdejší ministryně spravedlnosti Marie Benešová řekla, že <a href="https://www.psp.cz/eknih/2017ps/stenprot/034schuz/bqbs/b29622001.htm">současná vláda připravila</a> návrh, jehož cílem je <a href="https://www.psp.cz/eknih/2017ps/stenprot/034schuz/bqbs/b29622001.htm">otevřené transparentní výběrové řízení</a>. Právě tato vyjádření dokládají, že kabinet Andreje Babiše zákon prosazoval s důrazem na transparentnost.</p>
<p>Zákon byl ve Sbírce zákonů <a href="https://www.zakonyprolidi.cz/cs/2019-353">vyhlášen 20. prosince 2019</a> a <a href="https://www.zakonyprolidi.cz/cs/2019-353">účinnosti nabyl 4. ledna 2020</a>. Formulace, že ho Babišova vláda zavedla v roce 2020, tak sedí při výkladu podle účinnosti, i když byl <a href="https://www.zakonyprolidi.cz/cs/2019-353">přijat už v roce 2019</a>. Samotný zákon navíc mezi podmínky pro výkon funkce výslovně řadí <a href="https://www.zakonyprolidi.cz/cs/2019-353#p11">odborné předpoklady</a> a při projednávání zaznívalo, že má pomoci dostat do orgánů státních firem <a href="https://www.psp.cz/eknih/2017ps/stenprot/034schuz/s034074.htm">kompetentní odborné osoby</a>.</p>
<p><a href="https://www.psp.cz/eknih/2017ps/stenprot/026schuz/bqbs/b14703301.htm">Nominační zákon tedy skutečně prosadila vláda Andreje Babiše</a> a její veřejná argumentace i samotný text zákona mířily k <a href="https://www.psp.cz/eknih/2017ps/stenprot/034schuz/bqbs/b29622001.htm">transparentnějšímu</a> a <a href="https://www.zakonyprolidi.cz/cs/2019-353#p11">odbornějšímu výběru nominantů</a>. Proto výrok Víta Rakušana hodnotíme jako pravdu.</p>
