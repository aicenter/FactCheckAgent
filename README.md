# Evaluating fact checking capabilities of LLM agents

This folder contains the release package for AI fact-checking study performed with demagog.cz:
- `dataset/` with claims, checklist ratings, annotations, and AI fact-check outputs (`AIdev`, `AIv1`, `AIv2`)
- `fact_check_v1/` and `fact_check_v2/` agent code and prompts
- `data_analysis.ipynb` with quantitative analysis used for the report

Technical report: see `report.md`.
