# Step 2: Search for Sources

Recall `work/claim_interpretation.md` to understand what you are looking for.

Use web search to find evidence for each non-trivial sub-claim. Cast a wide net — find more sources than you think you'll need. Include both sources that support and sources that contradict the claim.

Write your findings to `work/raw_sources.md`.

## What to Write

For each source you find, record:

```
### Source N: [short description]
- **URL:** [full URL]
- **Domain:** [e.g., csu.gov.cz]
- **Type:** primary / secondary / media / official document / database / expert opinion
- **Language:** Czech / English / other
- **Publication date:** [date]
- **Relates to sub-claim:** [which sub-claim from claim_interpretation.md]
- **Key information:** [exact quote or data point from the source, in the source's language]
- **Supports or contradicts:** [supports / contradicts / provides context]
```

## Search Strategy

1. Start with primary sources: official statistics (csu.gov.cz, eurostat), legislation (zakonyprolidi.cz, psp.cz), government documents (vlada.cz, ministry websites).
2. Then search public broadcasting: irozhlas.cz, ceskatelevize.cz, ceskenoviny.cz.
3. Then search reputable media: seznamzpravy.cz, aktualne.cz.
4. If a secondary source cites a primary source, find and record the primary source too.
5. Search for contradictory evidence even after finding supporting sources.
6. Respect the date constraints from the "Date Constraints" section in claim_interpretation.md — only use sources published within the valid evidence window. Use search time filters to enforce this.
7. Avoid using the source of the evaluated claim as evidence to support or refute it.
8. Consider using the speaker's or their institution's social media accounts.
